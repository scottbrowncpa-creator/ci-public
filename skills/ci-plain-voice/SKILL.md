# Plain voice

AI-written text gets spotted fast by clients, auditors and coworkers. Plain, short, specific writing reads as a person and reads as more professional, not less. This skill is a checklist you run on a draft. It is not a style to imitate.

## How to use it

1. Paste the draft (or point at the file) and say "run ci-plain-voice on this".
2. Claude lists every hit from the find-list below, then returns a rewritten version.
3. Read the rewrite once against the original. Every number, name, date and account must be unchanged.
4. Fix anything that still sounds like a template. If a sentence could appear in any email to anyone, cut it or make it specific.

Works on email, Teams text, Excel notes, Word memos and slide text. It rewrites the words only. It never changes figures.

## Find-list (fix every hit)

- **Dashes.** No em-dashes or en-dashes. Use a plain hyphen with spaces, or a period. Never two hyphens in a row.
- **Arrows and fancy characters** typed into Excel or plain text. Use "to" and straight quotes.
- **Fancy words.** Replace: crucial, pivotal, robust, comprehensive, seamless, leverage, streamline, utilize, enhance, foster, delve, underscore, showcase, landscape, tapestry, testament, intricate, meticulous, vibrant, holistic, foundational, realm. Say the plain word: use, key, strong, full, improve.
- **Stand-ins for "is".** serves as, stands as, functions as, acts as. Write "is".
- **Filler.** It is important to note, worth noting, in order to, the fact that, in summary, in conclusion, overall, essentially.
- **Framing tricks.** "Not X, but Y." "Not only X but also Y." "This isn't a X. It's a Y." A closing sentence that repeats what you just said. Lists padded to exactly three items.
- **Chatbot lines.** Let me know, happy to, feel free, I hope this helps, here is a summary, would you like, certainly, great question.
- **Process talk.** "The model", "the script", "per the playbook". State the result, not how it was produced.
- **Label lines.** "Attached: file.xlsx" or "File:" lines. Write a sentence: "Attached is the August bank rec."
- **Placeholders and markup left behind.** [Name], [NEED: ...], **bold**, ## headings, backticks in an email or cell.
- **Vague sources.** "Documentation shows" or "sources confirm" when one file or one person is behind it. Name the file, tab or person.
- **Guess dressed as fact.** If you inferred it, say so ("guessing", "looks like", "may").

## Email

- Open with the ask or the answer. One idea per paragraph.
- Short sentences. Fragments are fine in internal mail.
- Name who does what. "Pat has August in process" beats "August is in process."
- Say what is attached in a plain sentence. Never paste a file path into an email.
- Questions beat directives with peers: "Should we add this to the SOP?"
- Give real times, not a question about times: "Tues 9am? Thurs 12-2?"
- No dates promised to a client unless you own the date.
- Cut disclaimers and next-step speeches. End when the ask is made.

## Workpaper and Excel notes

- No note over 40 words. Most run 6-15.
- No first person (I, we, my) in a workpaper.
- Numbered notes at the bottom; the row points to the number.
- Keep every number, account and date exactly as is. Cut reasoning before facts.
- An open question gets a yellow fill and a "?". Pick one answer; do not weigh two options in a cell.
- Do not start a note with "=" (Excel reads it as a formula).

Before and after:
- "Overspend is federal expenditure with no remaining entitlement. It becomes a General Fund cost." becomes "Fed exp over remaining entitlement. GF cost."
- "Beginning fund balance was never split by fund, which is why the totals differ." becomes "Beginning fund bal not split by fund."

## Leave alone

Source text is not yours to rewrite: vendor names, GL memos, account names, grant titles, contract and statute language, state form instructions, a client's own board narrative, anything already sent as a record.

## Before it goes out

- Any number changed? Put it back.
- Any dash character left? Search for it.
- Could this sentence be in anyone's email? Make it about this client and this month.
- If the file is a Word, Excel or PowerPoint file, also check File > Info for the author name. It should be yours.
